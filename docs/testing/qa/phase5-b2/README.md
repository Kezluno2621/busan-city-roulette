# Phase 5-B-2 Chromium QA 증적 인덱스

검증일: 2026-11-06 (Asia/Seoul)

실제 ChatGPT in-app Chromium에서 다음 화면을 시각 확인했다.

| 화면 | viewport | 확인 결과 |
|---|---:|---|
| 장소 목록 | 1440×900 | 12개 카드, 실제 이미지 11개와 정책 fallback 1개, 가로 overflow 없음 |
| 장소 상세 | 1440×900 | 실제 이미지, Leaflet 지도, 공급자·이미지 이용조건 표시 |
| 개인화 추천 | 1440×900 | 추천 카드 이미지와 fallback, 10개 카드, 가로 overflow 없음 |
| 룰렛 코스 | 1440×900 | 5곳 이미지, 서버 확정 순서와 카드 순서 일치 |
| 룰렛 코스 | 768×1024 | 카드 폭 619px, 이미지 폭 128px, 가로 overflow 없음 |
| 룰렛 코스 | 390×844 | 카드 폭 313px, 이미지 232×131px, 52px 실행 버튼, 가로 overflow 없음 |
| 장소 목록 | 360×800 | 1열 317px 카드, 이미지 315×197px, 가로 overflow 없음 |
| 저장 코스 상세 | 1440×900 | 3개 저장 장소 모두 실제 이미지 로드 |
| 즐겨찾기 | 1440×900 | 1개 카드 실제 이미지 로드 |

브라우저 자동화 도구가 이 실행의 캡처를 대화 내 증적으로 표시했지만 로컬 파일 저장 API를 제공하지 않아 신규 PNG/JPEG 바이너리는 만들지 않았다. 변경 전후 비교에 사용할 기존 Phase 5-B 캡처는 `../phase5-b/`에 보존되어 있다. 이 제한은 완료 문서에 미검증/미완료로 명시한다.
